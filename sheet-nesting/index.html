File formats and example Excel files

Excel / CSV: one row per part with columns for name, width, height and quantity, plus an optional material column (Material). Sizes are the flat blank size. Header names are recognised in English or Slovene (e.g. Naziv, Širina, Višina or Dolžina, Količina or Kos). Without a header the order is name, width, height, qty. The first worksheet is used.

XML: any element with width and height as attributes or child elements, for example:

<Parts>
  <Part id="Side panel" width="1180" height="640" qty="4"/>
  <Part><Name>Bracket</Name><Width>260</Width>
        <Height>140</Height><Qty>12</Qty></Part>
</Parts>

Copy for Excel puts the table on the clipboard. In Excel, click cell A1 and paste. Download CSV saves it as a file (semicolon separated, decimal comma) that opens in Excel with a double-click.
